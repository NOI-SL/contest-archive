You have been selected to participate in all-island selection round after being shortlisted from a 12 hour competition.But unfortunately the train your supposed to come is late and all the other participators have gone inside and the UCSC front door is locked.But luckily your friend Ashan has send you a hint to find the password.According to Ashan the password is the string which you get by reversing the occurences of the characters of "ACM-NOI" in the string Ashan sends you.
**Letters may appear in lowercase or uppercase**

## Input Format

Single line String

## Output Format

Single line string

## Constraints

1 <= len(String) <= 3 * 105
string consist printable ASCII characters

### Sample Input 0

```
mypAssword
```

### Sample Output 0

```
oypAsswmrd
```
