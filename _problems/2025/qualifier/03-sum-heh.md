You are given two integers $$A$$ and $$B$$. Your task is to calculate and print the sum $$A + B$$.

## Input Format

The input consists of two space-separated integers $$A$$ and $$B$$.

## Output Format

Print the sum $$A + B$$.

## Constraints

-   $$-1000 \leq A, B \leq 10000$$
-   $$A$$ and $$B$$ are integers.

### Sample Input 0

```
5 10
```

### Sample Output 0

```
15
```
