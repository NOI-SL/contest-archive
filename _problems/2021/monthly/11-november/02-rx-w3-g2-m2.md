Daphne, the Duchess of Hastings, gardens for a hobby and the queen is aware of this. Following a tea party at the King’s palace, the Queen gifts the duchess with seeds to 3 very rare species of plants in the kingdom. Let us call these Raven-Bearberry ("**r**"), Sneezing Saffron ("**s**") and Thite ("**t**"). Each of these looks very different from both the others.

The Duchess comes home and decides to plant these seeds in a row near the entrance to the Clyvedon Castle. But she has rather strange conditions. Daphne wants to ensure that once grown, the order in which any three adjacent plants appear together in the row is different for someone entering through the gate and for someone leaving. 

For example, the patterns "**tsr**" and "**strs**" suit her, while the pattern "**stsr**" does not. 

Oh, and one more thing! She wants to **minimize** the number of Raven Bearberry ("**r**") planted.

## Input Format

The first line contains single integer $$N$$, the length of the arrangement the duchess wants to plant.

## Output Format

Print the arrangement of seeds that satisfies all the constraints. (using "s","t" and "r")

If there are multiple answers, print any one of them.

## Constraints

$$1 \leq n \leq 20000$$

### Sample Input 0

```
4
```

### Sample Output 0

```
stts
```
